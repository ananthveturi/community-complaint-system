Connect Live Google Cloud Credentials
  1. Go to Google Cloud Console → Credentials.
  2. Click Create Credentials → OAuth Client ID (Application type: Web Application).
  3. Under Authorized redirect URIs, add: http://localhost:5000/auth/google/callback
  4. Add your Client ID & Secret to your .env file: 
    GOOGLE_CLIENT_ID=your_id.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=your_secret
